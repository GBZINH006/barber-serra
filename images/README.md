## 🎨 Dicas Importantes

### Formato
- Use **JPG** para fotos (melhor compressão)
- Use **PNG** apenas para logos com transparência
- Use **WebP** se quiser máxima otimização (compatibilidade moderna)

### Tamanho de Arquivo
- Mantenha cada foto com **menos de 500KB**
- Use ferramentas de compressão: [TinyPNG](https://tinypng.com) ou [Squoosh](https://squoosh.app)

### Nomes de Arquivos
- ✅ Use letras minúsculas
- ✅ Use hífen para separar palavras
- ✅ Sem espaços ou caracteres especiais
- ✅ Exemplo: `barbeiro-carlos.jpg`
- ❌ Evite: `Barbeiro Carlos 01.JPG`
